Optional: camera scanning without internet

By default the POS page loads the barcode-scanner library from the internet
the first time you tap "Scan with camera".

To make it work offline, download this file:
  https://cdn.jsdelivr.net/npm/html5-qrcode@2.3.8/html5-qrcode.min.js
and save it in this folder as:  html5-qrcode.min.js
The page uses this local copy first.
