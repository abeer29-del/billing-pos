# Billing POS - Point of Sale System

A full-stack Point of Sale (POS) and billing management web application built with Python, Flask, and SQLite.

##  Features
* **User Authentication:** Secure login and password management using Werkzeug hashing.
* **POS Interface:** Fast checkout workflow with support for offline camera barcode scanning.
* **Product & Customer Management:** Easily add, edit, and track inventory and customer history.
* **Invoicing & Reports:** Automated invoice generation and sales summary reporting dashboards.

##  Tech Stack
* **Backend:** Python, Flask, Werkzeug, SQLite3
* **Frontend:** HTML5, CSS3, JavaScript, Jinja2 Templates
